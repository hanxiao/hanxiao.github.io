14 · 价差、套利与对冲

前一章的策略都在赌单边方向。这一章换一个维度：不赌涨跌，而赌相对关系和风险转移。价差（spread）赌两个相关合约之间的差，套利（arbitrage）捕捉定价错误，对冲（hedging）则把不想要的风险卖出去。三者底层是同一套线性代数——理解了就理解了机构每天在做什么。

一、价差交易

价差交易（spread trading）：同时买入一个合约、卖出另一个相关合约，赌两者价差的变化，而非任一合约的绝对方向。

普通方向交易：买 ES，赌 ES 涨
价差交易：    买 ES + 卖 NQ，赌"ES 相对 NQ 走强"
            （即使两者都跌，只要 ES 跌得少，你也赚）

本质是对冲掉共同的市场风险（market risk），只保留相对表现的风险。

三类常见价差

1. 日历价差（Calendar Spread / 跨期价差）——同一品种、不同到期月份。如 买 ESU6（9月）+ 卖 ESM6（6月），赌两月份价差（受利率、分红预期影响）。主要用于移仓（第 6 章），也可交易基差结构（contango/backwardation）变化。

2. 品种间价差（Inter-market Spread）——不同但相关的品种。如 买 ES + 卖 NQ 赌大盘 vs 科技；买 ES + 卖 RTY 赌大盘 vs 小盘的轮动（rotation）。交易的是市场内部结构，不必押注大盘整体方向。

3. 期现套利（Cash-and-Carry / Index Arbitrage）——期货 vs 现货（一篮子股票或 ETF）。期货偏离理论公允价（第 10 章）时，机构同时反向操作锁定无风险价差，维持基差合理。散户基本无法参与，了解即可。

套利 vs 价差

无风险套利（arbitrage）：定价错误，确定利润 → 机构/HFT 专属
统计套利（stat-arb）：    相关性回归，概率优势 → 散户可参与

真正的无风险套利在成熟市场极稀少，且被高频机构（HFT）瞬间吃掉。散户能做的是统计套利：赌两个高度相关品种的价差回归历史常态。

配对交易（Pairs Trading）

1. 找两个历史高度相关的品种（如 ES 与 NQ）
2. 计算价差（或比值 ratio）的历史均值与标准差
3. 价差偏离均值 > 2σ → 做空价差（卖强买弱）
4. 价差回归均值 → 平仓获利

本质是把均值回归（第 13 章）应用到"两个品种的价差"上。价差比单一价格更稳定、更易回归，因为剥离了共同的市场方向。

配对交易就是协整（cointegration）的手工版，你已经掌握了全部数学。 两个品种各自非平稳（随机游走），但存在一个线性组合 ES − β·NQ 是平稳的——这就是协整。β 不是别的，正是把 NQ 回归到 ES 上的回归系数，也就是对冲比（hedge ratio）；剩下的残差 εₜ 才是你真正交易的对象。对 εₜ 标准化得到 z-score，再对它做均值回归（第 13 章）——和你给单一价格做 OU/AR(1) 是同一套机器，只是先做了一次降维投影把共同的市场方向消掉。

真正值得停下来想的是另一半：相关性 ρ 决定分散的真实价值。n 个名义赌注、两两相关系数 ρ，有效独立赌注数是 Nₑ = n / (1 + (n−1)ρ)。这个量你天天在算——它和协方差谱的参与率（participation ratio）(Σλ)² / Σλ²、嵌入矩阵的有效秩是一族姊妹度量：都在 ρ→0 时趋近 n、在 ρ→1 时塌到 1，本质都在量"有效维度"，只是 Nₑ 走方差口径、参与率走特征值口径，一般情形下数值相近而非严格相等。ρ→1 时 Nₑ→1：做多 ES+NQ+RTY 看似 3 注，实际可能不到 1.5 注的独立性。价差交易的全部价值，等价于把腿之间的 ρ 推到 0 甚至为负，从而把 Nₑ 顶上去。

拖动相关性 ρ 和赌注个数 n，看有效独立赌注 Nₑ 怎么塌缩。把 ES/NQ/RTY 想成三注 ρ≈0.9 的高相关持仓，注意 Nₑ 离 3 有多远——这正是"看似分散、其实只下了一个方向赌"的量化提醒。

价差交易的优势与风险

优势：① 波动更小（两腿对冲，回撤平滑）；② 保证金更低（SPAN 模型对对冲组合给优惠，第 5 章）；③ 抗系统性风险（大盘暴跌时受冲击小）；④ 交易"逻辑"而非"方向"（可表达精细观点）。

风险：① 相关性破裂（correlation breakdown）——历史相关不代表未来，关系断裂时价差不回归反而扩大；② 腿部风险（leg risk）——两腿不同步成交时暴露单边风险，用交易所的价差订单（spread order）一键下两腿缓解；③ 双倍成本（两份佣金/交易所费）；④ 低波动诱使上重仓，相关性一破裂放大的仓位造成大亏。

二、对冲

期货诞生的初衷不是投机，而是对冲（hedging）——转移风险。对冲是建立一个与现有敞口（exposure）相反的头寸，抵消潜在损失。

你持有：一篮子美股（多头，怕大盘跌）
对冲：  卖出股指期货（空头）
结果：  大盘跌 → 股票亏，期货空头赚 → 互相抵消

目标不是赚钱，而是降低不确定性。它像保险：付出成本，换取风险下降。

第一性原则：对冲是把"市场方向风险"转移给愿意承担它的投机者。投机者提供了对冲所需的流动性——这就是期货市场存在的根本意义。

对冲比率

对冲手数 = (组合价值 × 组合 Beta) ÷ 单手期货名义价值

Beta = 1   → 与大盘同步；Beta = 1.3 → 波动是大盘 1.3 倍

例子：持有 $250,000 组合、Beta ≈ 1.0，用 ES（名义 5000×$50 = $250,000）对冲 → 卖空 1 手 ES，基本完全对冲大盘风险。小组合用 MES（微型）：$25,000 组合 → 1 手 MES。Micro 让小组合也能精确对冲。

Beta 对冲就是一次 OLS 投影——你早就在用最小二乘做这件事，只是换了个名字。

最小方差对冲比 h* = Cov(资产, 期货) / Var(期货)，正是把资产收益对期货收益做一元回归（regression）的斜率。书里的 组合价值 × Beta 只是把斜率换算成手数：Beta 本身就是组合对指数的回归系数 β = Cov(r_p, r_idx) / Var(r_idx)。所以"估对冲比率"和"估回归斜率"是同一道题，连 Beta 不稳定（basis risk）都对应回归系数在样本外漂移。

几何上更干净：把组合收益向量投影到期货收益张成的一维子空间，对冲就是减掉这个投影分量。完全对冲 = 把组合投影到期货子空间的正交补（orthogonal complement），留下的残差正交于市场因子——这就是 alpha。你保留的暴露 = (1 − ρ²)·Var(r_p)，ρ 是组合与期货的相关系数，跟回归的判定系数是同一个 R²。延伸：用单一指数期货对冲多资产组合 = K=1 的因子模型，只能消掉市场这一个共同因子；想压掉行业/风格暴露就得多腿对冲（多元回归），跟在嵌入里做正交化、投影掉某个方向是同一套线性代数。

完全 vs 部分对冲，以及代价

完全对冲（full hedge）抵消全部市场风险，只剩选股 alpha；部分对冲（partial hedge）只对冲一部分，保留部分上涨参与——实务更常见。

对冲不是免费午餐：① 放弃上涨（对冲期间大盘涨，空头亏，抵消涨幅——这就是"保费"）；② 基差风险（组合与指数不完全一致，Beta 不稳）；③ 移仓与持有成本（第 6、10 章）；④ 保证金占用（SPAN 会给优惠）。

Beta 和组合价值会变，对冲需动态再平衡（rebalancing）。对个人投资者，"重大事件（财报、议息）前临时对冲、事件后解除"是性价比很高的做法。

对冲思维对投机者的启发

即使你只投机不持股：价差交易本质就是一种对冲（用一腿对冲另一腿）；组合层面的净敞口（net exposure）比单笔更重要；理解"谁在卖给你"——你的对手可能是在对冲的机构，理解他们的动机能帮你读懂价格。

本章要点

  • 价差交易赌相对关系不赌方向：日历价差（跨期/移仓）、品种间价差（ES/NQ/RTY 轮动）、期现套利（机构专属）。
  • 无风险套利属 HFT；散户做统计套利/配对交易 = 协整 + 对价差残差做均值回归。
  • 相关性 ρ 决定真实分散：Nₑ = n/(1+(n−1)ρ)，高相关持仓的有效注数远小于名义注数。
  • 对冲 = 转移风险、降低不确定性；对冲比 = OLS 投影斜率，完全对冲后残差即 alpha。
  • 代价：放弃上涨、基差风险、移仓成本、保证金；个人最实用是"事件前对冲、事件后解除"。
  • 共同风险：相关性破裂——价差和对冲都建立在相关性稳定的假设上，它一破，两者都失效。
