14 · 均值回归与区间

如果说趋势跟踪赌"动能延续"，那么均值回归（mean reversion）赌"过度的偏离会被纠正"。它是趋势跟踪的镜像策略，在震荡市场里赚趋势策略亏的钱。本章讲清楚它的逻辑、工具与陷阱。

核心理念

价格像被橡皮筋拴住：
拉得太远（偏离均值），就会被拉回来。

均值回归认为，价格短期会围绕某个"均值（mean / fair value）"波动。当价格因情绪或噪音过度偏离均值（超买或超卖），就有回归的倾向。交易者在极端处反向入场，等价格回到中枢获利。

        超买区（卖出）
   ──────●──────────────────
         │ ╱╲    ╱╲
均值 ────┼╱──╲──╱──╲────── ← 价格围绕均值波动
         │    ╲╱    ╲
   ──────●──────────────────
        超卖区（买入）

与趋势跟踪的对立统一

              趋势跟踪          均值回归
市场环境      趋势市            震荡/区间市
入场          顺势突破          逆势在极端处
胜率          低（35-45%）      高（55-70%）
盈亏比        高                低（小止盈）
最大风险      震荡锯齿          趋势爆发（被趋势碾压）

两者是互补的：没有任何单一策略适合所有市场。高手要么专精一种并只在适合的环境用，要么用过滤器在两种模式间切换。

识别区间与均值

确认震荡市（range）： - 价格在明确的水平支撑和阻力之间反复，无 HH/HL 或 LH/LL 的趋势结构。 - ADX 低（如 < 20-25），表示趋势弱。 - 均线走平、缠绕。

定义"均值"的工具： - 移动平均线（MA）：价格回归的中枢。 - VWAP（成交量加权平均价）：日内交易者极爱用的"当日公允价"，价格常回归 VWAP。 - 布林带中轨（Bollinger Band middle）：即一段均线。

衡量"偏离"的工具

均值回归的关键是量化"偏离多远算极端"：

布林带（Bollinger Bands） 均线 ± N 倍标准差（standard deviation）构成上下轨。价格触及上轨=偏离过高（潜在卖点），触及下轨=偏离过低（潜在买点）。

上轨 ─────────╲────────  ← 触及=超买，考虑做空
            ╱╲ ╲ ╱╲
中轨 ──────╱──╲─╳──╲───  ← 均值（目标）
        ╱      ╲  ╲
下轨 ──╱─────────╲────── ← 触及=超卖，考虑做多

RSI（相对强弱指数）

70 超买，< 30 超卖。均值回归者在 RSI 极端处反向操作。

Z-score（标准分） 价格偏离均值多少个标准差，是量化均值回归最严谨的度量。|Z| > 2 通常视为显著偏离。

一个区间交易框架

1. 确认环境：ADX 低 + 清晰的水平支撑/阻力
2. 入场：价格触及区间下沿 + RSI 超卖 → 做多
        价格触及区间上沿 + RSI 超买 → 做空
3. 止损：放在区间边界之外一点（一旦突破=可能转趋势）
4. 止盈：均值（中轨/VWAP）或区间对侧
5. 风控：盈亏比天然偏低，靠高胜率取胜，止损必须果断

致命陷阱：趋势碾压

均值回归最大的杀手是趋势启动。当区间被真突破（breakout）转为趋势，逆势的均值回归仓位会被持续碾压——"接飞刀（catching a falling knife）"，越摊越亏。

危险场景：
价格跌破区间下沿，你以为是超卖买点
→ 实际是下跌趋势启动
→ 价格一路下行，你的多单越套越深
→ 没止损 = 灾难

防御措施（不可省略）：

  1. 止损必须无条件执行。均值回归没有"扛单"的余地，一旦突破区间就是策略失效信号。
  2. 加趋势过滤：只在 ADX 低、无明显趋势时启用均值回归；高 ADX 时关闭。
  3. 避开重大数据/事件，它们最容易引爆趋势行情打破区间。
  4. 小止盈、严止损、高胜率，靠次数累积盈利，单笔绝不恋战。

日内均值回归：VWAP 战法

日内交易者常用 VWAP（Volume Weighted Average Price，成交量加权平均价）做均值回归：

  • VWAP 是当日所有成交按量加权的平均价，被视为"机构的成本线"。
  • 价格远离 VWAP（如 +2 标准差带）→ 考虑回归 VWAP 的反向交易。
  • 价格回到 VWAP 附近 → 止盈。
+2σ ───────●──────  ← 做空，目标 VWAP
          ╱ ╲
VWAP ────╱───╲────  ← 当日均值（目标）
        ╱     ╲
-2σ ──●────────── ← 做多，目标 VWAP

VWAP 战法在震荡的、无明显趋势的交易日有效，趋势日同样会被打爆，所以判断"今天是趋势日还是震荡日"是前提。

本章要点

  • 均值回归赌"过度偏离会被纠正"，在震荡市赚钱，与趋势跟踪互补。
  • 性格：高胜率、低盈亏比，靠次数累积，与趋势跟踪正相反。
  • 用 MA/VWAP/布林中轨定义均值，用布林带/RSI/Z-score 量化偏离。
  • 框架：低 ADX 区间 + 极端处反向入场 + 均值止盈 + 边界外止损。
  • 最大杀手是趋势启动碾压逆势仓，止损必须无条件执行，绝不接飞刀。
  • 日内常用 VWAP 均值回归，但必须先判断是趋势日还是震荡日。
