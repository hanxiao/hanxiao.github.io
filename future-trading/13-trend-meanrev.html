13 · 趋势与均值回归

方向性交易（directional trading）只有两种底层信仰：要么赌"动能延续"（趋势跟踪 trend following），要么赌"过度偏离会被纠正"（均值回归 mean reversion）。它们是同一枚硬币的两面，互为对手盘。这一章把两者放在一起讲——因为只有理解了它们的对立，你才知道当下该用哪一个。

一个参数，两种策略

把价格（或对数价、价差）的去均值收益序列写成一阶自回归 AR(1)：

rₜ = φ·rₜ₋₁ + εₜ

一个参数 φ 就分出了两个世界：

φ > 0  → 趋势/动能：涨了更可能继续涨，方向有记忆
φ ≈ 0  → 纯噪声：随机游走，两种策略都无能为力
φ < 0  → 均值回归：涨了更可能回落，偏离被纠正

              趋势跟踪          均值回归
底层信仰      φ > 0（延续）     φ < 0（回归）
市场环境      趋势市            震荡/区间市
入场          顺势突破          逆势在极端处
胜率          低（35-45%）      高（55-70%）
盈亏比        高                低（小止盈）
最大风险      震荡锯齿          趋势爆发碾压

没有任何单一策略适合所有市场。 高手要么专精一种、只在适合的制度（regime）里用，要么用过滤器在两种模式间切换。

趋势与均值回归是同一个 OU 过程的两端——你已经在高斯过程里采样过上千次。

AR(1) 的连续时间极限就是 Ornstein-Uhlenbeck 过程；其协方差是指数核 k(s,t) = exp(−|s−t|/ℓ)，也就是说一条价格路径等价于这个核下的一次高斯过程（Gaussian process）采样——你为了拟合超参数对它采样过上千次。φ 是同一根旋钮：φ→1（ℓ 大）是强趋势/接近随机游走的发散，0<φ<1 偏小是快速回归，φ<0 是过冲式振荡。z-score 就是把 rₜ 标准化成 rₜ/σ，和你在 embedding 里做白化、算 effective rank 前那步标准化是同一个动作。

两个可直接交易的量：信号半衰期 t½ = ln½ / lnφ——趋势侧 φ=0.9 约 6.6 步、φ=0.99 约 69 步（"高周期趋势更可靠"的定量版本）；回归侧 φ=0.4 时半衰期不到 1 步，这直接告诉你这笔均值回归仓位平均要拿多久，是定持仓时长，不靠拍脑袋设止盈。还有正偏态的来源：OU/AR 本身对称，但趋势侧"截断亏损+让利润奔跑"这一非线性出场规则，把对称分布削成了厚右尾（fat right tail）——偏度不是市场白送的，是你的出场结构造出来的。

诚实的警告，你比谁都懂：历史窗口估出的 φ̂ 方差极大、且制度会切换。把它当作过拟合到一段样本的"有效秩"幻觉，而不是稳定常数（第 23 章）。回归速度一旦漂移，止盈逻辑就失效——这正是这两类策略最容易过拟合的地方。

把 φ 拖到 0.3–0.5 看快速回归、拖到接近 1 看它退化成趋势；同时盯住 ACF 衰减曲线和半衰期读数——那个半衰期就是这类仓位的"自然持仓周期"。

一、趋势跟踪

趋势跟踪逻辑朴素到近乎平庸："顺着已形成的趋势交易，让利润奔跑，截断亏损"。但正是这种简单让它穿越了几十年市场考验。

核心理念：不预测，只跟随

趋势跟踪者不抄底摸顶、不预测拐点。他们承认无法预知未来，只在趋势确立后搭车、反转后下车——这是"右侧交易（right-side trading）"，等价格证明方向再行动。

它的盈利结构是正偏态（positive skew）：胜率往往只有 35%–45%，但盈亏比很高。大部分交易小亏，少数大趋势的盈利远超所有小止损之和。心理上很难受（频繁止损），数学上却稳健——这就是第一性原则的体现：截断亏损、让利润奔跑（cut losses, let profits run）。

识别与入场

回到第 11 章的高低点序列：连续 HH/HL（更高的高点和低点）= 上升趋势；连续 LH/LL = 下降趋势。常用确认工具：

  • 移动平均线（MA）：价格在 MA 上方且 MA 向上 = 上升趋势。双均线（如 20/50）金叉/死叉。
  • 均线斜率：均线本身的方向比价格与均线的关系更稳健。
  • 唐奇安通道（Donchian Channel）：突破 N 日最高/最低 = 趋势启动。著名的"海龟交易法（Turtle Trading）"用此入场。

一个可执行的骨架：

1. 方向过滤：价格在 50 周期 MA 上方 → 只做多
2. 入场：回调后突破前高，或突破 N 周期高点
3. 初始止损：最近的摆动低点（swing low）下方
4. 加仓（可选）：趋势延续时金字塔加仓，每次减小手数
5. 离场：移动止损（trailing stop）跟随，趋势破位才出

移动止损：让利润奔跑的灵魂

趋势跟踪的灵魂在离场。固定目标会过早离场、错过大趋势。用移动止损：

  • 跟随摆动点：止损跟着不断抬高的 swing low 上移。
  • ATR 跟踪止损：用平均真实波幅（ATR）动态设距离（如回落 3×ATR 就出），波动大时止损宽、小时紧。
  • 均线跟踪：收盘跌破某均线才离场。

原则：永远不要因为"赚够了"而手动平掉趋势单。 让市场用你的移动止损把你请出场。这是趋势跟踪者纪律的核心。

敌人：震荡市

趋势跟踪在震荡/区间市场（choppy market）会被反复打脸：假突破不断触发止损，连续小亏（"whipsaw 锯齿"）。用 AR(1) 语言说，这正是 φ 掉到 0 附近甚至转负的制度——你跟随的"记忆"消失了，此时只能给市场交"过路费"。应对：

  • 加趋势过滤器：如 ADX（平均趋向指标）低于阈值（20–25）时停止交易。
  • 接受连续亏损是系统的一部分，别因几次锯齿就放弃系统或频繁改参数。
  • 减少在低流动性、无方向的时段（如午盘）交易。

高周期（日线/周线）趋势更可靠、信号少、回撤大；短周期（5/15 分钟）信号多、噪音大。新手从较高周期起步，噪音少、决策慢、心理压力小。

二、均值回归

均值回归是趋势跟踪的镜像：价格像被橡皮筋拴住，拉得太远就会被拉回。它在震荡市赚趋势策略亏的钱。

识别区间与均值

确认震荡市：价格在水平支撑/阻力间反复、无趋势结构；ADX 低（< 20–25）；均线走平缠绕。

定义"均值"：移动平均线（MA）、VWAP（成交量加权平均价，日内"当日公允价"）、布林带中轨。

量化"偏离"

  • 布林带（Bollinger Bands）：均线 ± N 倍标准差。触上轨=超买（潜在卖点），触下轨=超卖（潜在买点）。k=2 约对应 95% 的两倍标准差边界。
  • RSI：>70 超买，<30 超卖。但强趋势中可长期超买/超卖，别单独用它逆势抄顶摸底。
  • Z-score（标准分）：价格偏离均值多少个标准差，最严谨的度量，|Z| > 2 视为显著偏离。

区间交易框架

1. 确认环境：ADX 低 + 清晰水平支撑/阻力
2. 入场：触区间下沿 + RSI 超卖 → 做多；触上沿 + RSI 超买 → 做空
3. 止损：区间边界之外一点（突破=可能转趋势）
4. 止盈：均值（中轨/VWAP）或区间对侧
5. 风控：盈亏比天然偏低，靠高胜率取胜，止损必须果断

致命陷阱：趋势碾压

均值回归最大的杀手是趋势启动。区间被真突破转为趋势时，逆势仓位会被持续碾压——"接飞刀（catching a falling knife）"，越摊越亏。

价格跌破区间下沿，你以为是超卖买点
→ 实际是下跌趋势启动
→ 多单越套越深 → 没止损 = 灾难

防御（不可省略）：① 止损无条件执行，突破区间就是策略失效信号；② 加趋势过滤，只在低 ADX 时启用，高 ADX 时关闭；③ 避开重大数据/事件（最易引爆趋势）；④ 小止盈、严止损、高胜率，靠次数累积，单笔绝不恋战。

日内 VWAP 战法

价格远离 VWAP（如 +2σ 带）→ 做回归 VWAP 的反向交易；回到 VWAP 附近 → 止盈。VWAP 战法在震荡日有效，趋势日同样会被打爆，所以先判断"今天是趋势日还是震荡日"是前提。

本章要点

  • 趋势 vs 均值回归 = AR(1) 的 φ>0 vs φ<0，互为对手盘，没有单一策略通吃所有市场。
  • 趋势跟踪：右侧入场、顺势、正偏态（低胜率高盈亏比），灵魂在移动止损，敌人是震荡市。
  • 均值回归：逆势在极端处、高胜率低盈亏比，靠 z-score/布林带/RSI 量化偏离，最大杀手是趋势碾压——止损必须无条件执行，绝不接飞刀。
  • 半衰期 t½ = ln½/lnφ 定持仓时长；ADX 是切换两种模式的开关。
  • 警惕 φ 的样本外漂移（过度拟合，第 23 章）；高周期更适合新手起步。
