16 · 希腊字母与波动率

上一章说期权的斜率会变。希腊字母（the Greeks）就是把"会变的斜率"量化出来的一组数字——它们是期权价格对各个因素的敏感度（sensitivity）。再加上波动率（volatility），你就拿到了期权交易的完整仪表盘。这一章是期权从"会买"到"会用"的分水岭。

五个希腊字母

每个希腊字母回答一个问题："当某个因素变化一个单位，期权价格变多少？"

Delta (Δ)  ← 标的价格变化的敏感度（一阶）
Gamma (Γ)  ← Delta 自身变化的敏感度（二阶）
Theta (Θ)  ← 时间流逝的敏感度（每天损耗）
Vega (ν)   ← 波动率变化的敏感度
Rho (ρ)    ← 利率变化的敏感度（最次要）

整套希腊字母就是期权价格 V(S, t, σ) 的多元泰勒展开——你给损失函数做二阶近似那套，原样照搬。

把期权价格对标的 S、时间 t、波动率 σ 展开：

dV ≈ (∂V/∂S)·dS + ½(∂²V/∂S²)·dS² + (∂V/∂t)·dt + (∂V/∂σ)·dσ + …
   =   Delta·dS  + ½·Gamma·dS²    + Theta·dt   + Vega·dσ   + …

一一对应：Delta 是一阶梯度（gradient），Gamma 是二阶曲率（对应 Hessian 的对角元），Theta 是对时间的偏导，Vega 是对 σ 的偏导。 你看 Hessian 判断一个点的凸性、用二阶项估计参数微调后 loss 怎么变——期权交易者用 Gamma 估计标的跳一下后 Delta 怎么变，是同一个动作。

两个直接的洞察：其一，Delta 对冲只是一阶近似，标的一大动，½·Gamma·dS² 这个二阶项就主导了误差——这就是为什么做市商要 Gamma 对冲，等价于你嫌一阶不够、上二阶法。其二，B-S 偏微分方程 Θ + ½σ²S²·Γ + rSΔ − rV = 0 把这些项锁成恒等式：Theta 和 Gamma 永远反号。long option 是 Γ>0, Θ<0（买凸性、付时间租金），short option 是 Γ<0, Θ>0（卖凸性、收租金扛负曲率）。"赚时间的钱"在数学上必然等价于"做空 Gamma"，没有又收租又有正凸性的免费午餐。

Delta：方向敏感度（一阶梯度）

Delta = 标的每变动 1 单位，期权价格变动多少。范围：Call 是 0 到 +1，Put 是 −1 到 0。

Delta = 0.5  → 标的涨 $1，期权涨约 $0.50
ATM 期权 Delta ≈ ±0.5
深度 ITM → |Delta| → 1（几乎像持有标的本身）
深度 OTM → |Delta| → 0（几乎不动）

两个实用解读：

  • 等效标的仓位：Delta 0.5 的一张 Call（100 股）≈ 持有 50 股的方向敞口。这是把期权换算成"等效标的"的方式。
  • 近似到价概率：Delta 的绝对值约等于该期权到期为价内（ITM）的概率。Delta 0.30 ≈ 30% 概率到价——交易者常用它快速估算胜率。

Gamma：Delta 的变化率（二阶曲率）

Gamma = 标的每变动 1 单位，Delta 变动多少。它衡量期权的凸性（convexity）。

Gamma 高 → Delta 变化快 → 盈亏加速（曲线很弯）
ATM、临近到期的期权 Gamma 最高
深度 ITM/OTM 的 Gamma 接近 0（曲线接近直线）

Gamma 是期权"曲线"的弯曲程度。买方（long option）总是 +Gamma：标的朝你方向动，Delta 自动放大盈利；朝反方向动，Delta 自动缩小亏损——这是买方天然的好处。卖方 −Gamma：方向对了 Delta 缩小、赚得越来越慢，方向错了 Delta 放大、亏得越来越快，这就是卖方危险的根源。

Theta：时间损耗（买方的敌人）

Theta = 每过一天，期权价格损失多少（通常为负）。时间价值会随到期临近而流失，且加速流失。

Theta = −5 → 其他不变，每天损失约 $5（每张 ×100）
价值
 │●─────╮ 时间价值
 │       ╲___
 │           ╲__
 │              ╲_ ← 临近到期，损耗加速
 │                ╲●
 └──────────────────▶ 到期
   90天   60天  30天  0
  • 买方付 Theta（−Θ）：你买的是凸性和时间，每天交"租金"。标的不动，你慢慢亏。
  • 卖方收 Theta（+Θ）：你卖时间价值，每天"收租"。这是卖方策略（如卖价外期权）的盈利来源。

Vega：波动率敏感度

Vega = 隐含波动率（IV）每变动 1 个百分点，期权价格变动多少。

Vega = 0.10 → IV 涨 1%，期权涨约 $0.10
ATM、长到期的期权 Vega 最高（对波动率最敏感）
  • 买方做多 Vega（+ν）：IV 上升，期权变贵，对买方有利。
  • 卖方做空 Vega（−ν）：IV 上升对卖方不利。

这就是为什么"事件前买期权、事件后卖"常常踩坑——见下面的 IV 部分。

波动率：期权真正的标的

期权价格的核心驱动，不只是标的方向，更是波动率。要区分两个概念：

历史波动率（HV, Historical Volatility）：
  标的过去实际波动了多少（回头看，已实现 realized）

隐含波动率（IV, Implied Volatility）：
  市场对未来波动的预期，从期权价格"反推"出来（向前看）

IV 是期权的"价格水位"。同样的标的、行权价、到期日，IV 越高，权利金越贵。交易期权很大程度上是在交易 IV：

IV 低时买期权 → 便宜，等波动放大获利
IV 高时卖期权 → 贵，收高额权利金（但承担风险）

IV Crush：新手最大的坑

隐含波动率压缩（IV crush）：重大事件（财报 earnings、议息）前，不确定性高，IV 被推得很高、期权很贵；事件一公布，不确定性消失，IV 瞬间暴跌，期权价格大幅缩水——哪怕你方向猜对了，也可能因为 IV 暴跌而亏钱。

财报前：股价 100，IV 80%，ATM Call 权利金 $8（贵）
财报后：股价涨到 105（你方向对了！）
        但 IV 暴跌到 35%，Call 只值 $6 → 你反而亏了 $2

铁律：事件前买高 IV 的期权 = 逆风作战。 你不仅要方向对、幅度够，还要赢过市场已经定价的波动预期。新手常因为"财报前买 Call 猜对方向却亏钱"而困惑，根源就是 IV crush。理解 IV，才算真正入了期权的门。

隐含波动率的结构

进阶认知（先了解）：IV 不是一个数，而是一张曲面：

  • 波动率微笑/偏斜（volatility smile / skew）：不同行权价的 IV 不同。股指期权通常呈现"偏斜"——价外 Put 的 IV 高于价外 Call，因为市场愿意为下跌保护付溢价（崩盘恐惧）。
  • 期限结构（term structure）：不同到期日的 IV 不同。
  • VIX：就是 S&P 500 期权 30 天隐含波动率的指数化表达——"恐慌指数"本质是 IV 指数。

希腊字母组合管理

实战中你看的不是单个期权，而是整个仓位的净希腊字母（net Greeks）：

净 Delta → 我整体是多头还是空头？方向敞口多大？
净 Gamma → 标的大动时我会加速赚还是加速亏？
净 Theta → 我每天是收租还是付租？
净 Vega  → 波动率上升对我有利还是不利？

专业期权交易者管理的是这四个数的组合，而不是"我看涨所以买 Call"。这是从散户到专业的认知跃迁。

本章要点

  • 希腊字母 = 期权价格的多元泰勒展开：Delta 一阶梯度、Gamma 二阶曲率、Theta 时间偏导、Vega 波动率偏导。
  • Delta：方向敏感度，≈ 等效标的仓位，绝对值 ≈ 到价概率。
  • Gamma：凸性。买方 +Gamma（动对了加速赚），卖方 −Gamma（动错了加速亏）。
  • Theta 与 Gamma 永远反号：买方付时间租金换凸性，卖方收租扛负曲率——没有免费午餐。
  • Vega + IV 是期权的"价格水位"；交易期权很大程度是交易隐含波动率。
  • IV crush：事件前 IV 高、事件后暴跌，方向对也可能亏——新手第一大坑。
  • 专业玩家管理的是仓位的净希腊字母组合，不是单纯"看涨买 Call"。
