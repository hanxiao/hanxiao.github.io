19 · 资产对比：期货·期权·股票·ETF 怎么选

你已经把四类工具都过了一遍：股票（stock）、ETF、期货（futures）、期权（options）。现在回答那个最实际的问题——同样想表达"我看涨 S&P 500"这个观点，到底该用哪个？ 这一章把四者摆在同一张台面上做正面对比，给你一套可以直接套用的选择框架。

同一个观点，四种表达

假设你判断"未来 S&P 500 要涨"。四种工具都能押这个注，但代价、风险、资金效率完全不同：

观点：看涨 S&P 500
├─ 股票：买 500 只成分股            → 笨重，几乎没人这么干
├─ ETF：买 SPY / VOO               → 简单，全额出资，长期持有
├─ 期货：买 1 张 ES / MES          → 高杠杆，线性，几乎 24h
└─ 期权：买 ES/SPY Call 或价差     → 非线性，有限风险，可赌波动

没有"最好"的工具，只有"最适合当前目的"的工具。 选错工具，对的观点也会亏钱。

五个维度的正面对比

维度 股票 ETF 期货 期权
本质 公司所有权 一篮子所有权 未来合约 权利/义务
盈亏结构 线性 线性 线性 非线性（凸）
杠杆 无（现金） 无/低 极高（内建） 高（权利金）
最大损失 本金 本金 可超本金 买方=权利金
资金占用 全额 全额 保证金（小） 权利金（小）
持有成本 无（收分红） 低费率 移仓基差 时间损耗 Theta
到期 无 无 有 有
交易时段 常规 常规 近 24h 多数常规
做空难度 难（借券） 难 易（直接） 易（买 Put）
能赌波动率 否 否 否 能
适合周期 长期 长期 短–中 短–中
上手难度 低 低 中 高

三个决策轴

把上表压缩成三个你做决策时真正要问的问题：

轴一：你要持有多久？

长期（数月到数年）→ ETF / 股票（无到期、无移仓成本、能复利）
短中期（数天到数周）→ 期货 / 期权（杠杆高效，但到期/损耗是成本）

期货和期权都会到期、都有持有成本（移仓基差 / Theta），天然不适合长期持有。想长期复制指数，ETF 几乎总是更优。

轴二：你要线性还是非线性？

只赌方向、想要确定的杠杆敞口 → 期货（线性，斜率恒定，简单直接）
想要有限风险、或赌波动率/时间 → 期权（非线性，凸性）

期货的 payoff 是直线，期权是折线/曲线。怕穿仓、想要内建止损 → 买期权（最大损失=权利金）；要纯粹高效的方向杠杆 → 期货。

轴三：你对波动率有看法吗？

没看法，只看方向 → 股票/ETF/期货
有看法（会大动/会横盘/IV 太贵太便宜）→ 期权（唯一能直接交易波动率的工具）

资金效率与杠杆的真相

很多人冲着"杠杆"来玩期货期权，但要看清杠杆的两面：

$25,000 资金，看涨 S&P（指数 5000）：

ETF（SPY）：买 ~$25,000，无杠杆
  指数 +10% → +$2,500（+10%）

MES 期货：1 张名义 $25,000，保证金可能仅 $1,500
  指数 +10% → +$2,500，但相对保证金 = +167%
  指数 −10% → −$2,500，可能触发追保甚至超过保证金

MES/SPY Call 期权：花 $1,000 权利金
  指数 +10% → 可能 +$2,000+（杠杆更高）
  指数 不动或跌 → 权利金可能归零（−100%）

第一性原则：杠杆不创造收益，它放大波动。 同样的本金，期货/期权让你用更少的钱控制同样的敞口——省下的钱是"资金效率"，放大的波动是"风险"。两者是一枚硬币。新手最容易犯的错：把"资金效率高"当成"可以下更大的注"，结果实际杠杆爆表（第 5、20 章）。

这张对比表本质是在 payoff 的函数空间里选基——线性基 vs 非线性基，和你选模型族是同一个决策。

把每种工具看成把"未来标的价格 S"映射到"你的盈亏"的一个函数 f(S)：

股票/ETF/期货： f(S) = a·S + b      线性（一阶），只有方向（均值/一阶矩）进入盈亏
期权及其组合：  f(S) = 非线性（凸） 二阶及以上矩（方差…）进入盈亏

选工具 = 选你的假设空间（hypothesis space）/ 函数族。期货是线性模型：参数少、可解释、敞口（梯度）恒定、没有"形状"自由度——你只能调方向和大小。期权是非线性模型：表达力强（第 17 章的 Carr-Madan 说任意 payoff 都能用期权基拼出来），但参数更多（行权价、到期、IV）、更容易过拟合你对行情的故事、且要付"租金"（Theta）维持那份凸性。

这就是经典的偏差-方差/表达力-代价权衡（bias-variance tradeoff）：观点简单粗暴（就是看涨、看长期）时，别上非线性——用 ETF/期货这个线性基，稳健、低成本、少一个出错的维度。观点精细（看涨但怕崩、或赌财报会大动、或认为 IV 被高估）时，线性基根本表达不了，才值得上期权这个高表达力函数族，并接受它的复杂度和租金。用最简单、够用的工具表达你的观点——这跟"能用线性模型就别上深网"是同一条奥卡姆剃刀。

典型场景 → 工具选择

把它落到具体场景，直接可用：

长期定投美股        → ETF（SPY/VOO），无脑复利，别碰期货期权
持有组合、临时避险   → 卖期货对冲 或 买 Put 保险（第 14、18 章）
短线看涨、要高效杠杆 → 期货（MES 起步），线性、24h、做多做空一样
看涨但怕穿仓         → 买 Call / 牛市价差，最大损失=权利金
赌财报/事件会大动     → 期权跨式（但防 IV crush！第 16 章）
赌横盘收时间租       → 期权铁鹰/备兑（绝不裸卖）
想做空大盘           → 期货做空（最简单）或 买 Put
对冲单一持股下跌      → 个股 Put
日内高频方向交易      → 期货（成本低、流动性好、税务优 1256）

一个常见误区：别用错工具

✗ 用期货长期持有复制指数 → 移仓基差成本累积，不如 ETF
✗ 用期权做单纯方向押注且长期持有 → Theta 慢慢吃光你
✗ 财报前买期权赌方向 → IV crush，方向对也亏
✗ 因为"期货杠杆高"就重仓 → 实际杠杆爆表，一次反向出局
✗ 因为"期权风险有限"就乱买价外 → 大概率归零，小赌怡情可以，当主力必输

每一条都是"工具本身没错，用错了场景"。先想清楚目的（周期/方向/波动看法），再选工具，而不是反过来。

本章要点

  • 同一个观点有四种表达（股票/ETF/期货/期权），没有最好，只有最适合目的。
  • 三个决策轴：持有多久（长→ETF/股票，短中→期货/期权）、线性还是非线性（纯方向→期货，有限风险/赌波动→期权）、对波动率有无看法（有→只能用期权）。
  • 杠杆不创造收益只放大波动；"资金效率高"≠"可以下更大注"——这是新手头号误区。
  • 选工具 = 在 payoff 函数空间选基：观点简单用线性基（ETF/期货），观点精细才上高表达力的期权，并接受其复杂度与租金（奥卡姆剃刀）。
  • 记住误区清单：期货别长持、期权别长持单腿、事件前防 IV crush、别因"杠杆高/风险有限"就乱下注。
  • 流程永远是：先定目的（周期·方向·波动），再选工具。
