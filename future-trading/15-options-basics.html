15 · 期权基础

期货是线性工具——盈亏随价格线性变化，斜率（delta）恒定。期权（options）是非线性工具，它在合约里塞进了一个"选择权"，于是盈亏变成了曲线。理解期权，等于给你的工具箱加上一整个新维度：你不再只能赌方向，还能赌波动率、时间、概率。本章打地基。

一句话定义

期权是一份合约，赋予买方在未来有权利、但无义务，以约定价格（行权价 strike）买入或卖出标的资产。关键就在"权利 vs 义务"——这是期权和期货最根本的区别。

期货：双方都有义务，到期必须履约 → 盈亏线性、对称
期权：买方有权利无义务，卖方有义务无权利 → 盈亏非线性、不对称

两种期权，四个角色

看涨期权（Call）：买方有权"买入"标的
看跌期权（Put）： 买方有权"卖出"标的

         买方（Long, 付权利金）      卖方（Short, 收权利金）
Call     赌涨，损失有限收益无限       赌不涨，收益有限损失"无限"
Put      赌跌，损失有限收益很大       赌不跌，收益有限损失很大
  • 买方（buyer / holder / long）：支付权利金（premium），获得权利。最大损失 = 权利金，损失有限。
  • 卖方（seller / writer / short）：收取权利金，承担义务。收益封顶 = 权利金，损失可能很大。

这是期权的灵魂：买方用确定的小成本（权利金），换取不确定的大收益；卖方收确定的小收益，承担不确定的大风险。 谁都不是免费的。

核心术语

行权价（strike, K）：约定的买/卖价格
到期日（expiration）：权利的截止时间
权利金（premium）：期权的价格，买方付、卖方收
标的（underlying）：期权对应的资产（股票/ETF/指数/期货）
合约乘数（multiplier）：美股股票期权通常 1 张 = 100 股

美股个股/ETF 期权一张（contract）对应 100 股标的。报价 $2.50 的期权，买一张实际花 $2.50 × 100 = $250。

内在价值与时间价值

期权的权利金由两部分构成：

权利金 = 内在价值（intrinsic value） + 时间价值（time value / extrinsic value）
  • 内在价值：立即行权能拿到的钱。Call = max(标的价 − K, 0)；Put = max(K − 标的价, 0)。
  • 时间价值：超出内在价值的部分，反映"未来还可能变得更值钱"的可能性。到期时归零。
价内（ITM, in-the-money）：有内在价值
  Call: 标的 > K    Put: 标的 < K
平值（ATM, at-the-money）：标的 ≈ K
价外（OTM, out-of-the-money）：无内在价值，全是时间价值
  Call: 标的 < K    Put: 标的 > K

盈亏图：期权的灵魂

期权的非线性，一张盈亏图（payoff diagram）就看懂。以买入 Call（long call，K=5000，权利金 50 点）为例：

盈亏
 │                          ╱  ← 标的越涨赚越多（收益无限）
 │                        ╱
 │                      ╱
 0 ─────────────●━━━━╱──────────── 标的价
 │             ╱ 盈亏平衡=5050
 │  ━━━━━━━━━╱  ← 标的 ≤ 5000，亏损封顶 = −50（权利金）
 │  最大亏损 −50
      4900  5000  5050  5100

特征一目了然：下方损失被削平（封顶 = 权利金），上方收益不封顶——这就是凸性（convexity）。这条折线就是期权区别于期货那条直线的全部秘密。

上面这个组件是期货的线性盈亏——一条直线，斜率（delta）恒为常数。期权的盈亏是折线/曲线，斜率会随标的价变化。把两者放在一起看，你就懂了"线性 vs 非线性"这句话的全部分量。第 16 章会专门量化这种变化的斜率（希腊字母）。

四种基本头寸的盈亏

Long Call（买涨）：    亏损封顶(权利金)，盈利随涨无限    → 看大涨
Long Put（买跌）：     亏损封顶(权利金)，盈利随跌很大    → 看大跌/买保险
Short Call（卖涨）：   盈利封顶(权利金)，亏损随涨"无限"  → 看不涨，收租
Short Put（卖跌）：    盈利封顶(权利金)，亏损随跌很大    → 看不跌，收租/接货

记忆要点：买方（long）盈亏图是"对勾"——亏损平、盈利翘；卖方（short）是买方的镜像翻转——盈利平、亏损翘。 卖方赚的是"大概率不发生"的钱，但小概率发生时会很痛。

为什么交易期权

相比直接买卖标的，期权给了你三件期货/股票给不了的东西：

  1. 有限风险的方向押注：买 Call/Put，最大亏损就是权利金，天然自带止损，不会爆仓式穿仓。
  2. 杠杆与资金效率：用小额权利金控制 100 股的敞口，回报率可以很高（风险也是）。
  3. 交易"方向"之外的维度：你可以赌波动率（会不会大动，不管方向）、赌时间（卖时间价值收租）、赌概率分布。这是期货完全做不到的。
期货能赌：涨 / 跌
期权能赌：涨 / 跌 / 波动大 / 波动小 / 横盘 / 时间流逝 …

期权买方在做的事，本质是买一份概率分布的"凸性"——你对 Jensen 不等式的直觉可以直接搬过来。

期权到期盈亏是标的价格的凸函数（convex payoff），比如 long call 的 max(S−K, 0)。对凸函数，Jensen 不等式给出 E[f(S)] ≥ f(E[S])——也就是说，在期望值之上，分布的离散度（方差/不确定性）本身就有正价值。这正是期权时间价值的来源：标的越可能大幅波动，那条折线被"撑"得越高。买期权 = 做多方差，卖期权 = 做空方差。

换个你更熟的视角：期货的 payoff 是线性的，f(S)=aS+b，此时 Jensen 取等号——线性函数下分布形状不重要，只有均值（一阶矩）进入定价，所以期货只让你赌方向（一阶）。期权把 payoff 弯成非线性，于是二阶矩（方差）开始进入定价——这就是为什么期权能交易波动率，而期货不能。delta 是一阶梯度、gamma 是二阶曲率（下一章），整套希腊字母不过是这个 payoff 函数对标的与时间的泰勒展开（Taylor expansion）各阶项。你给损失函数做二阶近似、看 Hessian 的那套直觉，原封不动适用。

风险警告

  • 期权会归零（也会到期作废）：买价外期权，若到期未到价，权利金 100% 损失。这不是"套牢等回本"，是直接清零。
  • 时间是买方的敌人：每过一天，时间价值流失（theta，下一章），标的不动你也在亏。
  • 卖方风险不对称："收租"看似稳定，但裸卖（naked）期权的尾部风险（tail risk）极大，一次黑天鹅能吞掉几个月的权利金收入。新手绝不裸卖期权。
  • 复杂度更高：期权有行权价、到期日、隐含波动率多个维度，比期货难掌握。先把方向性买方玩明白，再碰卖方和组合策略。

本章要点

  • 期权 = "权利 vs 义务"：买方有权无义务（损失有限），卖方有义务无权利（风险大）。
  • 两种（Call/Put）× 两方向（买/卖）= 四个基本头寸；美股股票期权 1 张 = 100 股。
  • 权利金 = 内在价值 + 时间价值；ITM/ATM/OTM 描述价内价外；时间价值到期归零。
  • 灵魂是非线性盈亏：买方对勾形（亏损封顶、盈利翘），卖方是其镜像。
  • 期权独有的能力：有限风险方向押注 + 资金效率 + 赌波动率/时间/分布（期货做不到）。
  • 风险：会归零、时间侵蚀、卖方尾部风险——新手只做买方，绝不裸卖。
