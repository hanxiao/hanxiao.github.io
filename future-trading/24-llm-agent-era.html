24 · LLM 与 Agent 时代

2023 年以来，大语言模型（large language model, LLM）和能自主调用工具的智能体（agent）涌入交易圈，伴随的是铺天盖地的"AI 帮你躺赚"叙事。这一章不卖梦。我们把 LLM 在交易里真正能做、真正不能做的边界划清楚，顺带看 2026 年两件让散户处境实质变化的事：数据成本的崩塌，和自营（prop）账户的真相。

LLM 真正能帮上的：更快地阅读，不是更准地预测

LLM 的核心价值，是把非结构化信息变成可用的结构化输入。这件事它确实做得好：

✓ 解析财报、纪要、新闻稿 → 抽取数字、事件、口径变化
✓ 把一段央行声明压成"鹰派/鸽派 + 关键变量"
✓ 跨语言、跨来源聚合（路透 + 交易所公告 + 期货持仓报告）
✓ 给自然语言策略描述生成代码骨架（仍需你逐行验证）
✓ 检索增强（RAG）：把你多年的交易日志变成可问答的知识库

注意这些全部是输入端的工作——读得更快、读得更全、读得更省力。检索（retrieval）和嵌入（embedding）能把你一周才看得完的材料压到一小时，但它们给你的是更快的阅读，不是水晶球。信息消化效率的提升，和"预测下一根 K 线"之间，没有直接的桥。

第一性原则：LLM 降低的是信息获取与处理的成本，不是降低市场的不可预测性。前者真实且可观，后者一厢情愿。

LLM 真正帮不上的：幻觉回测与过拟合放大器

LLM 在交易里最危险的两个失效模式，恰恰来自它最讨喜的能力——"流畅地编"。

幻觉回测（hallucinated backtest）。你让模型"回测一下这个策略"，它会给你一段语气笃定、数字漂亮、夏普 2.3 的报告——而它根本没碰过任何历史数据，整段都是续写出来的合理猜测。任何不是从你自己的数据管线跑出来的绩效数字，默认为零可信度。

过拟合放大器（overfitting amplifier）。LLM 让"生成一个策略"的边际成本趋近于零。一晚上让 agent 自动生成、回测、筛选上千套策略，再报告夏普最高那一套——这正是第 20 章讲的多重检验（multiple testing）问题被踩到油门。试验次数 N 从几十涨到上万，样本内最高夏普被纯随机性抬高的幅度按 √(2·lnN) 增长，通缩夏普（deflated Sharpe）的折扣只会越来越狠。自动化生成策略不创造优势，只制造更多噪声的最大值。

传统人工调参：     试 N≈50 套      → 已要打折
LLM/agent 自动搜： 试 N≈10000 套   → 折扣陡增，裸夏普几乎全是运气

工具越省力，越要把 N 如实记下来并扣回去。

0DTE 与数据民主化：2026 的两个真实变化

0DTE（zero days to expiration，当日到期期权）的爆发是真的。 CME E-mini 标普 0 到 5 DTE 期权的日均成交量（ADV）在 2025 年从约 35 万张涨到约 77 万张（约 +120%），其中纯 0DTE 部分约从 10 万张到 37 万张（数据约值，以交易所发布为准）。这意味着围绕指数期货的短期期权流显著变厚。

但"0DTE 对冲流通过 gamma 反馈推动指数期货"这个说法，目前是有争议的，不是定论：

两种对立的实证口径：
  Cboe（《SPX 0DTE 期权市场影响》）：
    做市商净 gamma 仅约占标普期货日内流动性的 0.04% 到 0.17%，
    未观察到可辨识的价格影响。
  SpotGamma 等：
    对冲行为确实在日内推动指数。

→ 别把"0DTE 造成尾盘剧烈波动"当成已证实的机制去交易。
  这是个开放问题，下注前先看你自己能复现的数据。

数据成本的崩塌是更确定、更重要的变化。 曾经只有机构付得起的期货行情数据，现在是几十到几百美元/月的事：Databento CME MDP 3.0 标准档约 199 美元/月（自 2026-06-22 起，约值以官网为准），Polygon 期货数据约 29 到 199 美元/月。过去要数万美元的东西，如今是低三位数美元。 数据这道墙基本塌了——这对散户是实打实的利好，也意味着"没有好数据"不再是借口。

工具链与"验证一切"

成熟的开源回测引擎已经很多：NautilusTrader、VectorBT（及 PRO）、Zipline-Reloaded、Lean 等。但工具成熟 ≠ 工具无 bug。2026 年一篇 arXiv 论文（2603.20319v1）就报告了 NautilusTrader 的持仓模式（position-mode）不匹配和回测被静默截断（silent truncation）——也就是说引擎在你不知情的情况下少跑了一段数据。

铁律：任何回测引擎的输出，都要用一个你手算得清的极简案例去对账。
  - 单笔进出，手算盈亏，看引擎是否一致
  - 检查它跑的数据区间是否就是你以为的区间
  - 持仓方向/数量的语义，逐一确认
工具会骗你，不是因为恶意，是因为默认配置和你的假设不一致。

这与第 20 章一脉相承：报告夏普必须披露试验次数 N 并打折（通缩夏普 DSR，Bailey 与 López de Prado, 2014）。LLM 时代 N 爆炸，这条纪律比以往任何时候都重要。

自营与"出资"账户：你买的是评估，不是资本

近年很火的 prop firm / funded account（自营公司 / 出资账户）——Topstep、Apex、FundedNext 等——值得说句大白话：

它们的商业模式本质：
  你付"评估费"（evaluation fee）参加考核（combine），
  通过后操作的是【模拟资金】，不是交易所里的真实资本。
  公司主要收入来自【报名费】，不是分你交易的利润。

这不是骗局，但要看清楚：这是个卖评估、给模拟盘的生意，不是有人真把交易所账户的钱交给你。配套的规则（如 Apex 的 30% 一致性规则——单日盈利不得超过总盈利的 30%）本身就是为压低通过率设计的。行业统计（QuantVPS, 2026）显示绝大多数参与者通不过考核。

值得注意的演化：Topstep 在 2026-01-27 推出了 Topstep Brokerage，FundedNext 也在进入期货——也就是说部分公司开始往真实经纪业务靠拢，模糊了"模拟考核"和"真实交易"的边界。但在你交易的那一刻，先问清楚：我赚的钱，是市场里的真钱，还是后台数据库里的数字？

这一章几乎是你的职业说明书——但正因为是你建的，你最该诚实。 你做了五年嵌入、重排器、ReaderLM、late chunking 和 RAG，没有人比你更清楚这套管线能和不能做什么。它能做的是把"读"做到极致：把财报、纪要、跨语言新闻压成结构化输入，把延迟从一周降到一小时。这是输入端的真实增益，别低估。

但要把两件事钉死在墙上：

  • 检索/嵌入 ≈ 更快的阅读，不是预测器。 你的 retriever 优化的是"在已有语料里找到相关段落"的召回，它从不承诺"下一时刻价格"。把召回率（recall）误读成预测力（predictive power），是把 IR 指标硬塞进一个 EMH-adjacent 的世界——公开信息在你读到时多半已被定价，剩下的边际信息量逼近噪声。这不是模型不够好，是信息论的地板。
  • LLM 是过拟合放大器，不是过拟合解药。 自动生成 + 自动回测把试验次数 N 从几十推到上万，样本内最高夏普按 √(2·lnN) 被抬高，而样本外 ≈ 0——和你在 Fashion-MNIST 上"扫一堆超参再报最好那个"是同一只野兽，只是 N 大了两个数量级。通缩夏普的折扣项里那个 N，现在是你 agent 一晚上的吞吐量。
  • 幻觉回测 = 续写，不是测量。 LLM 给你的"夏普 2.3"，在没接你数据管线时，信息增益（information gain）为零——整段都是先验语言模型的流形采样，没有一个比特来自市场。把它当措辞流畅的随机数。

一句话的直觉，用你的话说：你的工具把 μ̂ 的估计成本压到了零，但没有改变 μ 本身有多小、σ 有多大。 T 太小、N 太大时，μ̂ 几乎全是方差——你比谁都懂，别因为是自己造的锤子就忘了这件事。

本章要点

  • LLM 的真实价值在输入端：更快、更全、更省力地阅读与结构化信息；这是真增益，但和"预测价格"之间没有桥。
  • 两个致命失效：幻觉回测（没碰数据就编出绩效）与过拟合放大器（自动生成把试验次数 N 推到上万，夏普虚高更狠）。
  • 0DTE 成交量爆发是真的（CME 0-5DTE ADV 约 +120%），但"gamma 反馈推动指数期货"仍有争议：Cboe 测得影响微乎其微，SpotGamma 称有日内推动——别当定论交易。
  • 数据成本崩塌是更确定的利好：机构级期货数据从数万美元降到约 29 到 199 美元/月（Databento、Polygon，约值以官网为准）。
  • 开源回测引擎成熟但有 bug（NautilusTrader 持仓模式 / 静默截断），一切输出都要用手算极简案例对账；报告夏普必须披露 N 并打折（DSR）。
  • Prop / funded 账户本质是卖评估、给模拟盘的生意，收入主要来自报名费，多数人通不过考核；Topstep 已于 2026-01-27 推出真实经纪业务（Topstep Brokerage），边界在变。
