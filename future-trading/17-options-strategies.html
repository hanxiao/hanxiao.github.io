17 · 期权策略实战

掌握了四个基本头寸和希腊字母，就能把它们拼成应对各种行情的"招式"。期权策略的本质，是组合多条腿（legs）来塑造你想要的盈亏曲线——你先决定"我想要什么形状的 payoff"，再用期权拼出来。本章从单腿到组合，由浅入深。

策略的两个分类轴

按方向：看涨 / 看跌 / 中性（不赌方向，赌波动或时间）
按波动：做多波动（赌大动） / 做空波动（赌不动，收时间租）

每个策略都可以放进这张二维表里。选策略前先问自己两个问题：我对方向怎么看？我对波动率怎么看？

一、单腿方向策略（入门）

Long Call：  看大涨，亏损封顶=权利金，盈利无限           → +Delta +Gamma +Vega −Theta
Long Put：   看大跌/买保险，亏损封顶，盈利很大            → −Delta +Gamma +Vega −Theta

新手就从这里开始。最大亏损 = 权利金，天然自带止损、不会穿仓。代价是 Theta（时间损耗）和需要赢过 IV——方向、幅度、时机、波动率四个都要对。

二、备兑与现金担保（收租入门）

备兑开仓（Covered Call）：持有 100 股标的 + 卖出 1 张价外 Call。

持股 + 卖 Call 收权利金
→ 股价小涨/横盘：赚权利金（收租）
→ 股价大涨：股票被以行权价"叫走"，放弃超额涨幅
→ 股价跌：权利金提供一点缓冲，但仍承担下跌

适合"持有标的、看不大涨、想增强收益"。这是最稳健的卖方入门，因为有股票兜底，不是裸卖。

现金担保卖出看跌（Cash-Secured Put）：留足现金 + 卖出 1 张价外 Put。愿意在更低价"接货"，同时收权利金。股价不跌 → 赚权利金；股价跌破行权价 → 以行权价接货（成本被权利金降低）。

三、价差策略（控制风险的组合）

价差（spread）= 同时买一腿、卖一腿，用卖出的权利金补贴买入成本，牺牲部分收益换取更低成本/更可控风险。

垂直价差（Vertical Spread）——同到期、不同行权价：

牛市看涨价差（Bull Call Spread）：买低 K Call + 卖高 K Call
  盈亏都封顶，成本比单买 Call 低 → 温和看涨

 │  ╱

熊市看跌价差（Bear Put Spread）：买高 K Put + 卖低 K Put → 温和看跌

垂直价差是新手从"单腿"迈向"组合"的最佳一步：风险收益都封顶，Theta/Vega 敞口被部分对冲，不用赌得那么极致。

四、中性策略（赌波动，不赌方向）

这是期权独有的、期货完全做不到的玩法——不在乎涨跌，只赌"会不会大动"。

做多波动（赌大动）：

跨式（Straddle）：同时买 ATM Call + ATM Put（同行权价）
宽跨式（Strangle）：买 OTM Call + OTM Put（成本更低）

盈亏

 │ ╲                  ╱
 0 ─╲────────────────╱─── 标的
 │   ╲____________╱  ← 横盘不动 = 亏（双份权利金 + Theta）
     跌破        涨破

适合"预期要剧烈波动、但不知方向"（如财报、重大事件前）。但小心 IV crush（第 16 章）：事件前 IV 高、Straddle 很贵，事件后 IV 暴跌，标的动得不够大就双亏。这是新手买 Straddle 最常踩的坑。

做空波动（赌不动，收租）：

卖跨式 / 卖宽跨式：卖 Call + 卖 Put，赌标的横盘，收双份权利金
铁鹰（Iron Condor）：卖宽跨式 + 两端各买一腿做保护 → 风险封顶版收租

铁鹰是最受欢迎的中性收租策略：在标的两侧建立"价外卖出 + 更价外买入保护"，标的留在中间区间就赚权利金，且最大亏损封顶。它做空 Gamma、收 Theta——赚的是时间和"不动"的钱，怕的是突然大动。

期权组合就是用基函数线性组合去拟合一个目标 payoff 形状——和你拿核/基展开逼近一个函数是同一件事。

每条期权腿的 payoff 是一个"折线基函数"（hockey-stick / ReLU 形状的 max(S−K,0)）。多腿线性组合（买正系数、卖负系数）就能逼近任意你想要的到期盈亏曲线——这在数学上叫 Carr-Madan：任意光滑 payoff f(S) 都能写成一份债券 + 一份远期 + 对所有行权价的看涨/看跌期权的加权积分，权重正是 f″(K)（二阶导）。换句话说，期权行权价是一组基（basis），你在用它们做函数逼近，f″ 就是展开系数——和 ReLU 网络用无数个 max(0, x−b) 拼出任意函数、或你用核基展开逼近目标函数，是同一个结构。

落到希腊字母上更清楚：选策略 = 选你想要的 (Delta, Gamma, Vega, Theta) 组合。跨式是纯 +Gamma +Vega（做多曲率和波动、零初始 Delta）；铁鹰是 −Gamma +Theta（卖曲率收时间租）；垂直价差是把单腿的 Vega/Theta 敞口部分对冲掉、只留方向。你不是在"猜涨跌"，是在调一个四维向量——这正是你调超参数、在多个正则项之间做权衡的同款思维。

风险管理铁律

期权策略再花哨，风控原则不变（且更严）：

  1. 新手只做买方和有保护的组合（价差、铁鹰、备兑），绝不裸卖（naked short）。裸卖 Call 理论亏损无限，一次黑天鹅吞掉几个月收入。
  2. 每笔风险仍按账户的 1–2% 算（第 20 章），权利金全损就是你的最大风险（买方）/ 用价差封顶最大亏损（卖方）。
  3. 警惕 IV：高 IV 时别买、考虑卖；低 IV 时别卖、考虑买。事件前后尤其当心 IV crush。
  4. 管理到期与行权风险：临近到期 Gamma 暴涨，价内期权有被指派（assignment）风险，提前平仓或移仓，别拖到最后一刻。
  5. 流动性：选成交活跃、买卖价差小的期权（主流 ETF/指数期权），冷门期权进出都吃亏。

本章要点

  • 选策略先问两件事：方向看法 + 波动率看法，落进"方向 × 波动"二维表。
  • 入门顺序：单腿（Long Call/Put）→ 备兑/现金担保（有兜底的收租）→ 垂直价差（风险收益封顶）→ 中性组合（铁鹰/跨式）。
  • 中性策略是期权独门绝技：赌波动不赌方向——跨式做多波动，铁鹰做空波动收租。
  • 期权组合 = 用折线基函数拼出目标 payoff（Carr-Madan），等价于选一个 (Δ,Γ,ν,Θ) 四维向量。
  • 铁律：新手只做买方和有保护组合，绝不裸卖；时刻盯 IV 防 crush；管理到期/指派/流动性。
